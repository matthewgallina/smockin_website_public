API Mocking


Whether mobile, web or microservices based, most modern applications are built upon a number of API based services.

With so many moving parts, setting up the right development environment can be complex and time consuming.

As many software teams are finding, simulating 3rd party APIs can greatly simplify and expedite product delivery.

Featuring a rich user interface, sMockin is a free open source tool allowing you to build, manage and monitor API mocks.


"Expedite product delivery by rapidly simulating 3rd party APIs"


"Build dynamic mocks with JavaScript or without code using rich visual tools"


"Intercept & edit HTTP traffic in real time"


API Traffic Monitoring


Another challange delivery teams often face is a lack of visibility when it comes which APIs were called and precisely what was sent and received.

Already providing realtime monitoring out the box (so you can trace calls to your mocks), sMockin can also be easily set up as a proxy server on any development machine enabling you to gain a clear insight of all API traffic to and from your app.

Another great benefit of running sMockin as a proxy server is the ability to replace existing API call with mocks and even block and edit responses in realtime.


"Swap out existing or missing API services using proxy mode"


"Avoid blocking development on APIs that aren't readily available"

Quick Start




Source Installation (requires JDK 11 & Maven 3)


1. Run git clone https://github.com/matthewgallina/smockin.git
2. Run mvn clean install
3. Run the install and then start scripts


Docker Installation


1. Run docker run --name smockin -d -p 8000:8000 -p 8001:8001 -p 8002:8002 -p 8003:8003 mgallina/smockin:2201



Accessing Admin & Mock Servers


1. Open the sMockin dashboard http://localhost:8000/index.html
2. Follow the Creating a Simple Mock guide at www.smockin.com/help
3. Access your API mock GET http://localhost:8001/helloworld
4. Access your S3 bucket mocks by connecting to http://localhost:8002/
