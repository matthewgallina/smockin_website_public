Configuration & Troubleshooting

Configuration File Overview


(Please note, the following applies to all versions of sMockin, apart from the Docker image.)

All of sMockin's configuration, database and log files can be found under the .smockin folder within the root of your user home directory (this folder may be hidden by default on some operating systems).



(At this point it is worth highlighting that running the sMockin uninstall script will remove this directory, so it you plan to reuse sMockin again in the future, please ensure you make a copy of this as a back up.)


From here the files and folders listed are as follows (please note these will vary depending on your operating system):

app.properties - used to set the ports of the main admin application and H2 DB as well as change sMockin from standalone and multi user modes.
db - contains the H2 DB (JDBC) driver and data files.
logs - contains log output from the main admin application and mock server.
pids - contains the process IDs of both the admin application and H2 DB when running (only applies to linux and OSX).






Enabling Multi User Mode


sMockin can be run either as a Standalone Tool installed to each user's computer (this is the default setting), or it can be configured to run in Multi User Mode where a single installation is centrally hosted and user's access the platform with individual user accounts.

To enable multi user mode, shutdown sMockin and then simply open the app.properties file and set the multi user property to true like so: MULTI_USER_MODE = TRUE.

Once saved, start up sMockin and use the default username and password admin to login.



From here, you can change the admin user's password and begin setting up user accounts by clicking on Tools in the top right hand corner.



Troubleshooting & Debugging


Should you encounter an issue either starting up sMockin or whilst the application is running, your first action should be to check the smockin.log application log to see if this offers any clues as to what is failing.

In the rare event the log file does not offer any insight or is not actually present in the USER_HOME/.smockin/logs/ directory, you can try downloading the sMockin source project from Github and launching the application using the command: run.sh -CONSOLE

For any developers working on sMockin, there is also the option to launch using DEBUG mode as follows: run.sh -CONSOLE -DEBUG

Running this will enable you to remote connect to the application from your chosen IDE using port 8008.
