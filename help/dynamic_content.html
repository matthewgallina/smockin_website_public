Response Variables

Dynamic tokens allow you to include certain content dynamically within the response body of your mock.


For example, say your mock features a request parameter called 'name' and you wish to include the value of this within the response body of your mock, this can be done using the $requestParameter token like so:

Hello $requestParameter('name'), How are you?


Other inbound params such as request headers, params, path variables and the request body itself are also supported:

$requestHeader('header name')
$requestParameter('param name')
$pathVar('path var name')
$requestBody


ISO Date and Time values are also available like so:

$isoDate
$isoDatetime


The below token can be used to generate a random UUID:

$uuid


You can generate random numbers using the following:

$randomNumber(10)
$randomNumber(5, 10)


Any stored key / value data can be referenced using the following:

$lookUpKvp('KEY')
$lookUpKvp($pathVar('path var name'))
(For more details on key / value data, check out the Using Stored Key/Value Data help section)
