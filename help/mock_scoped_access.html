Calling Your Mocks

Below are a few examples of how to access your mocked endpoints from port 8001 using cURL:

Standalone Mode

curl -i -X GET http://localhost:8001/helloworld

curl -i -X GET http://localhost:8001/v1/hello

curl -i -X POST http://localhost:8001/v1/home -H 'Content-Type: text/plain' -d '1 Privet Drive'


Multi User Mode

curl -i -X GET http://localhost:8001/bob/helloworld

curl -i -X GET http://localhost:8001/bob/v1/hello

curl -i -X POST http://localhost:8001/bob/v1/home -H 'Content-Type: text/plain' -d '1 Privet Drive'
