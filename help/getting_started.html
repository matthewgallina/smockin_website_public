Getting Started

Welcome!


This section will help you familiarise yourself with the dashboard of the sMockin API mock tool.

Once you have installed sMockin locally to your machine, you can access the main dashboard from here http://localhost:8000/index.html

Below is a breakdown of the dashboard:




1. All your mocks are batched by path name and listed alphabetically.
2. The HTTP method and full path name of the mocked endpoint.
3. The date the mock was created.
4. The type used for the mock (See 'The Different Mocking Types' for more info).
5. Highlights whether the mock is currently enabled or not.
6. The 'View' button, opens up the editor and shows the inner workings of the mock.
7. Expands / Collapses the batched mocks on view.
8. Bulk operations to view / select mocks from the dashboard.
9. Opens mock server configuration settings.
10. The current status of the mock server.
11. Control to Start / Stop the mock server.
12. Bulk operations to Delete, Import / Export mocks on the dashboard.
13. Opens the mock editor for creating a new mock.
14. Drop down menu with links to Live Feed Logging Tool, HTTP & WS Clients and Help pages.
15. Opens proxy settings, for running sMockin as a proxy server.
