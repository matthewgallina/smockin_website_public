Installation

The sMockin API tool can be installed in a number of ways detailed below:

Standalone & Binary

(binary requires Java 8)

1. Download & unpack the appropriate zip archive
2. (Windows & Binary) Run the install and then start scripts
    (Mac OSX) Copy the sMockin app to your Application folder & then launch the app*
3. Open the sMockin dashboard http://localhost:8000/index.html

*(OSX security may initially block the app from launching. To change this go to System Preferences > Security & Privacy)


Source

(requires Java 8 & Maven 3)

1. Run git clone https://github.com/matthewgallina/smockin.git
2. Run mvn clean install
3. Run the install and then start scripts
4. Open the sMockin dashboard http://localhost:8000/index.html


Docker


1. Run docker run --name smockin -d -p 8000:8000 -p 8001:8001 mgallina/smockin:2150
2. Open the sMockin dashboard http://localhost:8000/index.html
